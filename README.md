# King Concrete Pumping — Liquid Screed

Single-page **service** microsite for King Concrete Pumping, focused on the
liquid screed service across the South East (Surrey, Kent, Sussex and South London).

Static build on the approved King Concrete template: plain HTML, CSS and a little
vanilla JS (mobile nav, FAQ accordion, screed volume calculator). Self-contained —
fonts, images and icons are all local, nothing loads from an external URL.

## Preview locally

```bash
python3 -m http.server 8795
```

Then open http://localhost:8795/

## Content source

Copy and facts are taken from the hub's own floor screed page
(kingconcretepumping.co.uk/floor-screed) — service areas, underfloor-heating
positioning, pumped-screed benefits — with real King Concrete screed photography.
Testimonials are genuine 5-star Google reviews.

Eventual domain: kingconcrete-liquidscreed.co.uk (not yet pointed).
